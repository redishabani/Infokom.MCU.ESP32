# Infokom.MCU.ESP32
>Libs, apps, demos and garbage code for ESP32 micorcontroller unit family


## Repository Structure

- `.\S3\Apps\` — Contains specialized application projects using the `Infokom.MCU.ESP32.S3.Apps.<app-name>` naming convention.
- `.\S3\Libs\` — Shared proprietary and core drivers designed to minimize code duplication across apps.
